# What House Account does

House Account helps answer questions about home repairs and other home services.

For example: "Who has worked on this house before?" or "Which handyman might have two free hours this week?"

The program reads files from several business tools. It sorts the information, checks for repeated records, and saves the results in a local database. A database is a file that stores information in a form the program can search.

An AI assistant asks the program questions through MCP. MCP is a shared way for an assistant to call a tool and get an answer.

The program can show past work, planned visits, and possible openings. It cannot book a visit, take payment, or contact a provider.

The data is a supplied practice dataset. It is not a live feed from real businesses. For these examples, "today" means November 2, 2026.

The source files, database, and private answers stay out of GitHub. Another person needs the supplied files to run the program.

The main features are built. Live updates, travel planning, and checks that a user owns a home are not built.
