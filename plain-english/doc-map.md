# Why there are so many documents

The original docs do four different jobs.

**Guides** tell you how to run a task, such as setup or a query.

**Reference pages** list words, commands, rules, and fields.

**Explanations** tell you why the program is built this way.

**Execution records** say what happened during an earlier test run.

You do not need to read them all in order. Start with [the overview](project-overview.md), [the data model](data-model.md), and [how openings work](p3-design.md).

Older reports describe older code. A sentence such as "availability is not built yet" may be true for that report's date. It does not describe the latest program.

The plain-English versions keep those dates and limits clear. The [start page](README.md) links to every version.
