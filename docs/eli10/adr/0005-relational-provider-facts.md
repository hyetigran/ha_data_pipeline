# A claimed service area is not proof of past work

A plumber may say it serves a ZIP code even when the supplied history contains no completed jobs there.

The program stores claimed coverage separately from observed completed work. It also stores aliases, trades, and exclusions as linked records.

That makes filtering possible without turning a business's claim into a proven work history.
