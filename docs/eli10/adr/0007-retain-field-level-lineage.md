# Keep the evidence for each chosen value

Knowing which file a job came from does not explain every value added later.

A ZIP code might come from the street reference. A house-number correction might come from a person's review. The program keeps those reasons with the chosen facts.

No source wins every disagreement. A newly imported record is not automatically the newest fact about the business.
