# Describe the work without exposing private notes

Calling a gate repair "other" loses useful detail. Copying the whole source note could expose private information.

The program uses recognized facts and approved wording to describe the service. It keeps the original note private.

If it cannot classify the work, it uses a general description and flags the gap. It does not invent a more precise repair.
