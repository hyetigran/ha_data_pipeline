# One job can contain several kinds of work

A handyman might fix a wall and paint a room under one job. A single service label would lose part of that work.

The program stores each listed service separately. It also says whether the wording was understood, unknown, or conflicting.

Listed work is still not completed work. Each service needs supporting evidence before it receives credit as performed.
