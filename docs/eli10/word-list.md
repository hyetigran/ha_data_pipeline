# What the words mean

| Word in the docs | Plain meaning |
| --- | --- |
| Provider | A business that does work, such as a plumber. |
| Property | A home or other place where work happens. |
| Job | The whole piece of work. It may need several visits. |
| Visit | One appointment for work or an estimate. |
| Estimate | Proposed work or a price quote. It does not prove the work happened. |
| Job lifecycle | Whether the whole job is open, active, finished, cancelled, or unknown. |
| Service category | The kind of work, such as water-heater work. |
| Service description | Safe details about the work, without private notes. |
| Service completion | Evidence that work happened. The exact date may still be unknown. |
| Service attribution | Evidence that a particular kind of work was done. |
| Distinct jobs | Different jobs counted once each. |
| Completed visits | Separate appointments that have evidence of completion. |
| Alias | Another name for the same business. |
| Declared service area | Where the business says it works. |
| Observed service area | Where records show that the business has done work. |
| Canonical identity | The saved ID for one matched business, home, or other item. |
| Field lineage | The evidence behind one chosen value, such as a house number. |
| Unresolved property link | A job's home has not been safely identified. |
| Visit parent | The job or estimate that the visit belongs to. |
| Job service | One kind of work listed on a job. Listing it does not prove it happened. |
| Estimate service | One kind of work proposed in an estimate. |
| Working hours | When a business says it normally works. Those hours may already be booked. |
| Calendar event definition | One event, or a rule such as "every Friday at 9." |
| Delivery scope | What a file or update claims to cover, such as one business's week of visits. |
| Complete snapshot | A checked full set of records for a stated scope. |
| Partial change batch | A few changes, not the full set of records. |
| Source deletion | A source says it removed a record. That does not mean a job was cancelled. |

A time can be **known**, **missing**, **ambiguous**, or **disputed**. Ambiguous means more than one reading is possible. Disputed means the evidence challenges a value.

"No apartment number" and "the apartment number is missing" are different facts. A blank price also differs from a price of zero.
