# How AI helped and where people still decide

Codex helped compare designs, write code, add tests, write docs, and review the work.

The project checked the results in several ways: code tests, real terminal commands, real MCP calls, and recorded assistant answers.

AI use is not proof that the result is right. A successful tool call is also not proof that the assistant explained the result correctly.

One early demo asked about a street without giving Dallas, Texas. Codex asked for the missing location. Separately, the test checker accepted a resource-list call without a schedule query.

The revised test supplies the location and requires the correct tool. The revised video explains the two problems separately.

People still decide whether to approve real record matches and corrections. Tests use disposable decisions. Private files and captured answers stay outside GitHub.
